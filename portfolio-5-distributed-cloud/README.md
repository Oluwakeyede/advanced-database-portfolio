# Portfolio 5: Distributed and Cloud Database Exercise

## Overview
This portfolio explores how distributed and cloud database concepts can support the operations of West Haven Hotel & Suites using MongoDB Atlas.

## Tools Used
- MongoDB Atlas
- Python
- PyMongo

## Database Details
- Database: `west_haven_hotel`
- Cluster: `WestHavenCluster`
- Collection: `bookings`
- Records migrated: 40 booking documents

## Concepts Covered
- Database replication and replica sets
- Consistency and availability
- Sharding and scalability
- Cloud database deployment
